## 📌 About the project

**Randeasy** is a small Android app designed to make random number generation quick and easy.

This project was created **primarily as a learning exercise** to study and practice:

* **Kotlin**
* **Jetpack Compose**
* **Android app architecture**
* **State management with ViewModel**
* **Modern UI development with Material 3**

So while Randeasy is a functional app, its main purpose is to serve as a hands-on project for improving Android development skills and exploring best practices in a real application.

---

## ✨ Features

### 🎯 Current features — `v0.1.1 Beta`

* Generate random numbers within a **custom range**
* Choose **how many numbers** should be drawn
* Simple and intuitive random number generation flow
* **Modern Android UI** built with **Jetpack Compose**
* **State management with ViewModel**
* **Material 3** design foundation

This repository is part of my learning journey in Android development.

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/Guviega/Randeasy.git
```

### Open in Android Studio

1. Open **Android Studio**
2. Click **Open**
3. Select the cloned **Randeasy** folder
4. Let Gradle sync the project
5. Run the app on an emulator or Android device
